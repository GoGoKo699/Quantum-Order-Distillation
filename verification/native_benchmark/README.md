# Native one-, two-, and three-call benchmark

This directory verifies the fixed qubit measure–prepare channel
$K_0=\lvert+\rangle\langle0\rvert$,
$K_1=\lvert-\rangle\langle1\rvert$ with global logical order-basis
dephasing. The analytical statements and complete proofs are the
[three-call frontier](../../science/native_three_call_frontier.md#native-three-call-frontier)
and the [randomized call-cost envelope](../../science/randomized_call_cost.md#convex-call-cost).
The controller noise acts after routing and before final controller processing.
The accepted target-only channel averages the fine controller/correction label;
its aggregate success is input independent, although arbitrary fine outcomes
need not be.

This rank-deficient fixed-channel benchmark has a different metric, noise model,
and order architecture from the full-Choi-rank four-call
[physical local-noise frontier](../../science/recovery_frontier.md).
Its error is the accepted target-only half-diamond distance from identity.
Its cost counts compulsory noisy calls per accepted fresh trial. The duration
interpretation assumes a scalar logical-dephasing law; it does not establish a
hardware or equal-time advantage.

## Run the checks

Use Python 3.11 or later. The independent exact invariance program needs only
the standard library:

```bash
python3 verification/native_benchmark/verify_exact_invariance.py --output-dir /tmp/quantum-order-native-check
```

The complete finite suite additionally uses NumPy, SciPy and Matplotlib, with
the versions used for the recorded outputs pinned separately:

```bash
python3 -m pip install -r verification/native_benchmark/requirements.txt
python3 verification/native_benchmark/verify_complete_closure.py --output-dir /tmp/quantum-order-native-check
```

The output directory is created when needed. These commands preserve the
committed JSON records and write fresh results to the chosen directory. If
`--output-dir` is omitted, each program writes beside itself. Add
`--skip-figures` to the complete suite to run every check without generating
the two cost/noise plots. Both commands exit nonzero if a required assertion
fails. They use no network access or SDP solver.

The helper [prior_three_call_certificate.py](prior_three_call_certificate.py)
defines the native projectors, corrected branch Choi operators, and exact
rational branch identities imported by the complete suite. Its optional
standalone check also accepts `--output-dir`.

## What is established by computation

| Program or data | Exact or numerical coverage |
|---|---|
| [verify_exact_invariance.py](verify_exact_invariance.py) | Reconstructs all 16 target-coordinate kernels from integer Kraus words; checks 96 exact slot-relabeling invariances, 32 trivial/standard zero-block identities, 32 sign-sector zero-side identities, projector ranks and constant diagonals, all four Bell diagonal kernel identities, and the cross-Bell zero/support structure. |
| Same exact program | Uses rational arithmetic to compare the unequal-noise closed predicate with direct cumulative-vertex comparisons at 2,727 grid/boundary/near-boundary points. Its final duration-root bisection and logarithm are floating-point diagnostics, separately identified in the output. Finite predicate tests support the analytical phase proof; they do not prove the continuum statement by enumeration. |
| [verify_complete_closure.py](verify_complete_closure.py) | Reconstructs rational branch certificates and the priority hull, trial weights, acceptance, cost and saving exactly. Checks the piecewise priority cost formula at 204 rational noise values and the exact sign bracket for the conditional duration threshold. |
| Same complete program, numerical checks | Checks 549 native three-call acceptance points against a linear program and direct Choi contractions; 350 raw-flow/hull comparisons; 100 additional resource-weight cases; 250 arbitrary complex controller-Gram strategies with sampled continuum unitary corrections; 2,475 phase-grid cases; and 1,500 activation cases. These are finite numerical consistency checks, rather than the arbitrary-controller converse or a general diamond-norm optimization. |
| [exact_invariance_audit.json](exact_invariance_audit.json) | Recorded exact-kernel and rational-phase results, with the numerical duration diagnostic and physical scope identified. Regenerated by the exact program. |
| [complete_closure_results.json](complete_closure_results.json) | Recorded complete-suite counts, exact priority values, and numerical residuals. Regenerated by the complete program. |
| [exact_cost_and_noise_constants.json](exact_cost_and_noise_constants.json) | Readable rational constants, hull vertices/segments, symbolic noise boundaries and the exact polynomial sign bracket used by the scientific account. It is a record of derived formulas, not an input that makes either verifier pass. |

The complete suite checks the Bell-diagonal attaining channels by direct Choi
trace norms. Their equality to the half-diamond error, the controller reduction,
the global frontier converse, and the convex-resource and continuum noise
statements are justified analytically in the linked science pages. The sampled
complex-controller test evaluates a Bell-overlap upper bound; it does not
assert input-independent success for every sampled fine outcome.

A successful complete run reports `status: PASS` and zero positive global
witness violation. At $\eta_2=\eta_3=9/10$ and error budget $3/8$, the exact
priority values are cost $183/62$, baseline cost $101/32$, relative saving
$203/3131$, aggregate acceptance $62/63$, and raw trial probabilities $1/21$
for one call and $20/21$ for three calls. The recorded maximum numerical
residuals are approximately $1.11\times10^{-16}$ for the native knapsack/LP
comparison, $5.75\times10^{-16}$ for the direct Choi error, and
$6.22\times10^{-15}$ for raw-flow versus convex-hull cost.

The exact program reports 96 invariance equalities, 2,727 unequal-noise test
cases and zero mismatches. Rational identities are checked exactly; small
last-digit variation in floating-point diagnostics is expected across numerical
libraries. See [unequal noise](../../science/randomized_call_cost.md#unequal-noise)
and the [conditional duration model](../../science/randomized_call_cost.md#duration-model)
for the scope of the threshold interpretations.
